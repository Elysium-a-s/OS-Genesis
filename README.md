# C-C-OS-CU
OS for central unit

The central unit's persisted identity and integration relationships are
documented in the [PostgreSQL `integration` ER model](https://github.com/Elysium-a-s/PostgreSQL/blob/main/docs/er-diagrams/integration.md)
and its [Confluence page](https://sarockylukas.atlassian.net/wiki/spaces/Elysium/pages/36208731).
This repository does not currently define a firmware data store or database schema.
