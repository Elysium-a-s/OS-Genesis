# Panel

Všetky nové Genesis používateľské rozhrania sa vyvíjajú v jednom projekte Flutter/Dart. Patrí sem nástenný alebo stolový kontrolný panel pre iPadOS, osobný iPhone klient a webový dashboard. Natívny Linux panel sa posúdi podľa pilotného hardvéru.

iPad verzia má panelový layout pre miestnosti, zariadenia a rýchle scény; web a iPhone majú rozloženie prispôsobené obrazovke. Všetky varianty čítajú Genesis API. Oprávnenia vynucuje core na serveri, nie iba Flutter UI.

Existujúca Elysium iOS aplikácia v Swifte zostáva samostatná; s Genesis sa prepája cez API alebo deep link. Implementácia Genesis panelu zatiaľ neexistuje.
